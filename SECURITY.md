# Security policy

Security fixes are considered for the currently maintained ERYDON source on the
default branch.

After the public repository is created, report a vulnerability through its
private GitHub Security Advisory form. Do not include exploit details, tokens,
private server information, world data, or player identifiers in a public
issue. If private reporting has not yet been enabled, open a minimal issue that
asks the maintainers to enable a private reporting channel without describing
the vulnerability.

Ordinary crashes, compatibility problems, and gameplay bugs should use:

<https://github.com/erydon-mod/erydon/issues>
